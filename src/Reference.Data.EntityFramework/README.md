# Norse.Reference.Data.EntityFramework

Canonical reference-data entities (`Region`, `CountryOrArea`), the `ReferenceDbContext`, and `CountryOrArea`'s `View` owned-JSON ancestor chain (a `RegionNode`, hydrated at seed time — `null` only for Antarctica). Runtime library — referenced by the migrations tooling and Mímir's serving layer.

Part of the [Norse Architecture](https://github.com/NorseArchitecture) platform.
